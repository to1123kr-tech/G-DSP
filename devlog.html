2026.09.29
VWorld 인증키 단일화 — 지적도가 안 나오던 문제 해결 완료
증상 위성사진은 나오는데 지적도만 안 나옴. 그것도 특정 PC에서만.
원인 브라우저가 localStorage 에 저장된 키를 서버 키보다 먼저 쓰고, 값이 있으면 서버(/api/vworld/key)에 아예 묻지 않았다. 그래서 키를 바꾸기 전에 접속했던 PC는 죽은 키를 계속 들고 있었다. 위성사진은 카카오 키라 멀쩡했기 때문에 "사진은 되는데 지적도만 안 된다"로 보였다.
• map.html · popup_download.html · index.html — 서버 키를 항상 받아와 덮어쓰도록 수정
• 키 조회보다 지도 초기화가 먼저 끝나는 경우를 위해 _applyVworldKey() 추가 (WMS 레이어 키 교체 · 위성 타일 URL 교체 · 카카오 오버레이 재요청)
• popup_download.html — PROXY 를 선언 전에 참조해 undefined 가 되던 버그도 수정
• 옛 이름(gdsp_vworld_key)으로 남아있던 죽은 키도 지우도록 처리
→ 이제 사용자는 새로고침만 하면 자동 복구. 키 갱신 시 서버의 gdsp_vworld_key.txt 한 곳만 고치면 모든 PC에 반영된다.
